1. התקנה והפעלה

דרישות מקדימות

  • Node.js 18+ מותקן
  • Adobe Premiere Pro 2024+
  • מפתח Anthropic API (claude.ai → API)

הפעלת השרת

1
פתח טרמינל בתיקיית הפרויקט
cd /path/to/royibsclub
2
צור קובץ .env בתיקיית server
# server/.env
ANTHROPIC_API_KEY=sk-ant-api03-...
OPENAI_API_KEY=sk-proj-...        # לזיהוי קול (אופציונלי)
GOOGLE_SERVICE_ACCOUNT_JSON=./google-service-account.json
VIDEOS_OUTPUT_DIR=~/Videos

אפשר גם להגדיר ישירות מהממשק בטאב ⚙️ הגדרות.

3
הפעל את השרת
cd server
npm install
npm run dev

השרת יעלה על http://localhost:3333. תראה: Premiere AI Server running

התקנת התוסף ב-Premiere

1
בנה את התוסף
cd plugin
npm install
npm run build
2
העתק את התוסף לתיקיית Premiere

Windows:

%APPDATA%\Adobe\CEP\extensions\PremierAI\

macOS:

~/Library/Application Support/Adobe/CEP/extensions/PremierAI/

העתק את תוכן תיקיית plugin/dist/ לשם.

3
הפעל Premiere ופתח את התוסף

Window → Extensions → Premiere AI Studio

✅ אם ה-LED הירוק בפינה הימנית עליונה של הפלאגין דולק — השרת מחובר!

2. הגדרת API Keys

לחץ על טאב ⚙️ (הגדרות) בפלאגין להגדרת כל המפתחות מממשק נוח.

שירות לאיזה פיצ'ר נדרש
Anthropic צ'אט, Pipeline, ניתוח, מחקר חובה
OpenAI (Whisper) זיהוי דיבור אוטומטי בכתוביות אופציונלי
Google Service Account גאנט Pipeline מ-Google Sheets אופציונלי

קבלת Anthropic API Key

  1. כנס ל-console.anthropic.com
  2. API Keys → Create Key
  3. העתק את המפתח והדבק בטאב ⚙️ הגדרות

קבלת OpenAI API Key (לזיהוי קול)

  1. כנס ל-platform.openai.com
  2. API Keys → Create new secret key
  3. הדבק בטאב ⚙️ הגדרות תחת "OpenAI API Key"

3. חיבור Google Sheets (לגאנט)

Pipeline מושך נתונים מ-Google Sheets. זה אופציונלי — אם לא מחבר, Pipeline לא יעבוד.

1
צור Service Account ב-Google Cloud
  1. כנס ל-console.cloud.google.com
  2. IAM & Admin → Service Accounts → Create
  3. הורד JSON Key (Actions → Manage Keys → Add Key → JSON)
  4. שמור את הקובץ כ-google-service-account.json בתיקיית server
2
הפעל Google Sheets API
  1. APIs & Services → Enable APIs → "Google Sheets API" → Enable
3
שתף את הגאנט עם ה-Service Account

פתח את Google Sheets → שתף → הדבק את ה-email של ה-service account (כמו my-sa@project.iam.gserviceaccount.com) → Editor.

📊

📁

6. עבודה עם כתוביות

זיהוי דיבור אוטומטי (Whisper)

  1. ייצא אודיו מ-Premiere (או השתמש ב-MP3 מ-ElevenLabs)
  2. בטאב ✏️ כתוביות → לחץ "🎙️ זהה קול"
  3. בחר קובץ (mp3 / wav / mp4 / m4a)
  4. הטקסט ימולא אוטומטית
⚠ נדרש OpenAI API Key בטאב ⚙️ הגדרות. עלות: כ-$0.006 לדקה.

עיצוב כתוביות עברית

  • מילים בשורה — 2-5. מומלץ 3 לרילס, 4 ליוטיוב
  • עברית חכמה — לא שובר אחרי מילות חיבור (של, עם, את, כי...)
  • פיסוק — "הסר" לכתוביות נקיות, "שמור" לכתוביות עם ניקוד
  • מ/שנ — מהירות הדיבור (ברירת מחדל 2.5). עדכן לפי הדמות
  • התחלה — עיכוב בשניות לפני הכתובית הראשונה

ייצוא

  • העתק SRT — מוכן לייבוא ל-Premiere (File → Import → .srt)
  • העתק טקסט — טקסט נקי לשימוש חיצוני

7. ניהול דמויות

הטאב 🎭 מאפשר לשמור פרופיל לכל דמות. Claude מקבל את הפרופיל בכל Pipeline ומתאים את התסריט.

שדות פרופיל דמות

  • ID — חייב להתאים בדיוק לשם בעמודה D של הגאנט (עברית)
  • תיאור ויזואלי — תיאור באנגלית לפרומפטים לתמונות (גיל, לבוש, מיקום...)
  • טון דיבור — "ישיר, חם, מקצועי, עם הומור קל"
  • אישיות — רקע ומי הדמות
  • סגנון דיבור — משפטים אופייניים, ביטויים שהדמות משתמשת בהם
  • סוגי תוכן — "טיפ מקצועי, סיפור אישי, ריאקציה" (מופרד בפסיקים)

Brain Editor (בטאב Pipeline → Knowledge → Brain)

ערוך ישירות את הוראות הכתיבה של Claude — ה-"brain" שמנחה את כל התסריטים. שמור ← נכנס לתוקף מיד.

8. טיפים וטריקים

🏆 Pipeline — לתוצאות טובות יותר

  • כתוב הוק ספציפי בגאנט (לא "הוק טוב" — אלא "האם ידעת ש...")
  • הגדר דמות עם פרופיל מלא לפני הרצה
  • עדכן ביצועים בהיסטוריה — Claude ילמד מה עבד
  • ערוך את ה-Brain בטאב Knowledge לפי השפה והסגנון שלך

✏️ כתוביות — טיפים

  • לרילס קצר (30 שנ) — 3 מילים בשורה, 2.8 מ/שנ
  • לסרטון ארוך (3+ דקות) — 4-5 מילים בשורה, 2.2 מ/שנ
  • תמיד בדוק את הקובץ SRT ב-VLC לפני ייבוא ל-Premiere

⚡ קיצורי דרך

  • LED ירוק = שרת מחובר, LED אפור = שרת לא רץ
  • כל שמירה ב-Brain מנקה cache אוטומטית — אין צורך לאתחל שרת
  • הגדרות מה-UI גוברות על .env (שימושי לבדיקות)
  • קבצי JSON (דמויות, מותג, היסטוריה) ניתנים לעריכה ידנית ב-server/src/data/
